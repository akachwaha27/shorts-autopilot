Privacy Policy

Shorts Autopilot is used only by its owner to upload videos to the owner's own YouTube, Instagram and TikTok accounts.

Data we access

With the owner's consent, the app uses the YouTube Data API scope youtube.upload solely to upload videos the owner has approved to the owner's channel. It does not read, collect or store any other Google user data, and it does not access data of any other users.

Storage and sharing

OAuth tokens are stored as encrypted secrets in the owner's private configuration and are never sold, shared, or transferred to third parties. No personal data is used for advertising.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
